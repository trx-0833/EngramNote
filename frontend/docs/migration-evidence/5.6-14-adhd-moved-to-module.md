## 3. 三条机器证据

1. **规则清单差集**（`5.6-02-rule-diff.md`）：本批 **逐字保留 5 / 值有变化 0 / 丢失 0**。
   ⚠️ 工具这一轮补了一条归一化：压缩器会**压掉组合器两侧的空白**
   （源码 `.a > .b` → 产物 `._a_h>._b_h`），不归一化会把 4 条带 `>` 的规则整条报成"丢失"
   —— 这是本仓库第一次迁移带子组合器的规则（`neutralSelector`，规范 §7 第 11 条）。
2. **产物校验**（`5.6-03-built-css.md`）：切片标记 `adhdReaderActive` / `adhdBlock` /
   `adhdCurrentBlock` / `adhdLineMarker` 在产物里各命中 5 / 3 / 2 / 1 次；
   四个 kebab 类名进 `RETIRED` 后命中 **0**；悬空动画 0；改动范围内冲突 0；
   级联得主与媒体查询覆盖战、简写 vs 长写全部照旧。
3. **真 Chromium 渲染对账**（一次性探针，用完已删；配方见计划 §5 雷区 3）：
   两侧都用**产物**（`vite preview`）：迁移前 = `git worktree add --detach <tmp> HEAD`
   + `npx vite build`（只读 HEAD，不碰工作区）；迁移后 = 当前工作区的 `dist`。
   探针按 **DOM 结构**取样（不按类名 —— 类名哈希后按类名取样会让两侧取到不同元素）：
   容器 `.markdown-body` + 它的 6 个子元素（5 个正文块 + 行级标记条）+ 1 个链接，
   共 **8 个样本 × 全部 computed 属性 = 4 328 条值**（不是只挑那几条）。
   实测：**未声明的差异 0 条**；class 属性按预期 **7 个变哈希 / 1 个一字不变**
   （那个链接本来就没有类名），行内 `style`（渐变模糊与标记条定位由 JS 写入）**逐字相同**。
   探针自身的三个坑都处理了：块切换有 3 帧滞回（一次 `mousemove` 不够）、
   必须等过渡结束（≥600ms）、落盘不能用 `node:fs`（`e2e/` 在 `tsconfig` 的 include 里，
   而本项目没有 `@types/node`）—— 这条与计划 §5 雷区 18 记的是同一批坑。
