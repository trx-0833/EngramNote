# 问答页面重构（DeepSeek 网页版范式）+ 后端适配

> 状态：**阶段 1 实施中**（2026-11-14 起）
> 决策来源：用户确认「全部三段，但不做赞踩反馈」；引用栏「卡片内折叠 + 宽屏保留右栏」；
> 会话栏「时间分组 + 搜索 + 重命名」。

## 1. 为什么重做

现在的 `/qa` 是"居中对话流 + 右侧 300px 常驻引用栏 + 抽屉式历史"。
功能齐了，但**找会话要开抽屉**、**输入框随内容滚动**、**每条回答没有操作入口**
（只有失败/中止轮次有「重试」），与用户日常习惯的 DeepSeek 网页版差距明显。

## 2. 目标形态（照搬什么、不照搬什么）

| DeepSeek 特征 | 我们怎么做 |
| --- | --- |
| 左侧常驻可折叠会话栏 | 新增侧栏（宽屏 ≥1024px 常驻、可折叠；窄屏仍用现有抽屉） |
| 按「今天 / 7 天内 / 30 天内」分组 | 前端按 `updated_at` 分组（**零后端改动**，纯函数 + 单测） |
| 会话栏顶部搜索 | 接已有 `GET /api/qa/sessions?keyword=`（后端已转义 + `max_length=100`） |
| 悬停「重命名 / 删除」 | 删除已有；重命名需 **新增 `PATCH`**（阶段 2） |
| 中间消息流（用户右侧气泡、助手通栏） | 重排样式，保留现有渲染逻辑（含失败/中止三态） |
| 流式光标 | 流式中在答案尾部加一个 `▍` |
| 代码块一键复制 | 本轮不做（答案目前按纯文本渲染，没有代码块高亮） |
| 底部粘性输入区（多行自适应、Enter 发送） | 输入区改为 `sticky bottom`，`Enter` 发送 / `Shift+Enter` 换行 |
| 每条回答底部操作行（复制 / 重新生成） | 复制（前端）、重试（已有）、**重新生成**需 `retry_of`（阶段 3） |
| 空态大标题 + 推荐问题 | 空态改为标题 + 3 张推荐问题卡片（点一下填入输入框） |
| 顶部模型切换 | `GET /api/llm/models` + 请求体 `model`（阶段 3，取决于模型侧能力） |
| 右侧常驻引用栏 | **保留**（RAG 卖点），但每条回答下方**另有**可折叠来源条；窄屏只有条 |

**明确不做**：附件上传（我们有自己的笔记库，语义不同）、语音输入、赞/踩反馈（用户已排除）。

## 3. 三阶段与接口契约

### 阶段 1 · 纯前端（后端零改动）

- 新布局：`.qaShell` = 侧栏 + 主区 + 右栏（宽屏 grid，窄屏单列 + 抽屉）。
- `qa/SessionList.tsx`：列表项 + 时间分组 + 搜索（受控），**抽屉与侧栏共用**，
  这样现有 23 条抽屉测试继续有效（不删断言）。
- `qa/QAHistorySidebar.tsx`：宽屏常驻、可折叠（折叠状态存 `localStorage`）。
- 消息流：用户右侧气泡、助手通栏、流式光标、失败/中止三态不变。
- 每轮操作行：复制（`navigator.clipboard`）、重试（复用 `RetryButton` 语义）。
- 来源：卡片下方 `<details>` 式折叠 + 宽屏右栏（右栏仍只显示最新一轮）。
- 输入区：粘性底部、`textarea` 自适应高度（最多 200px）、`Enter` 发送 / `Shift+Enter` 换行。
- 空态：标题 + 3 张推荐问题卡片。

### 阶段 2 · 小接口

| 接口 | 契约 | 注意 |
| --- | --- | --- |
| `PATCH /api/qa/sessions/{session_id}` | 请求 `{title: str(max_length=80)}`，响应 `QASessionResponse` | 空标题 → 422；不属于当前用户 → 404；`surface` 校验同 GET |
| `GET /api/qa/sessions/{session_id}?before=<turn_id>&limit=N` | 游标分页，返回该轮**之前**的 N 轮（升序） | 与现有 `turns_limit`（取最近 N 轮）并存：`before` 优先 |
| 前端 | 侧栏搜索接 `keyword`（300ms 防抖）；消息流顶部「加载更早」按钮 | `has_more` 字段由后端给出，避免前端猜 |

### 阶段 3 · 语义改动

| 接口/字段 | 契约 | 语义决策 |
| --- | --- | --- |
| `POST /understanding/ask/stream` 增 `retry_of: Optional[str]` | 指向被重试的 `qa_turns.id` | ① 上下文只取**该轮之前**的 ok 轮次；② 旧轮标 `superseded`，列表/详情默认不返回；③ `turn_count` 只计未被替换的轮次 |
| `GET /api/llm/models` | `{models: [{id, label, scene}], default}` | 前端顶部下拉；请求体增 `model`，非白名单 → 422 |
| `qa_turns.status` 增 `superseded` | — | 迁移用 `_migrate_sqlite`（项目不用 Alembic） |

## 4. 风险与约束

- **`QA.tsx` 会被大面积重排**（现 778 行）。约束：state / handler 不动，只换 JSX 结构与样式；
  抽屉组件保留（窄屏 + 现有测试），新侧栏复用同一份 `SessionList`。
- 门禁：每阶段跑 `tsc / lint / vitest / build`，涉及页面的阶段加跑 `e2e` 与 `a11y`；
  后端改动跑离线套件 + `dump_openapi --check`。
- **不允许为了变绿删断言**；结构变化只允许更新定位方式（如 `getByRole` → `getByRole('navigation')`）。
- a11y：新侧栏是 `<nav aria-label>`，折叠按钮带 `aria-expanded`；来源折叠用 `<details>/<summary>`（原生键盘可达）。
