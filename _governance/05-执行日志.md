### 第 3 轮的两个新坑

**坑 1：覆盖率配置放 `pyproject.toml` 不生效**

- 现象：加了 `[tool.coverage.run] omit`，但 TOTAL 仍是 **16247** 句（预期 14314）
- 原因：pytest 在 `backend/` 下执行，coverage 从**当前目录**找配置；根目录的 `[tool.coverage.run]` 未被读取
- 修法：改放 `backend/.coveragerc`（INI 格式）。改后 TOTAL **14281**，mineru/asr/embedding/test_support 不再出现
- 教训：**"配置写了"≠"配置被读到"**。判据是数字变化，不是文件存在

**坑 2：lefthook 的两个 Windows 陷阱**

- 陷阱 A：默认 `python` 指向 `D:\miniforge3\python.exe`（base，无 ruff）→ 钩子报 `No module named ruff`，**看着像代码错，其实是解释器错**。修法：`${PYTHON:-python}` + 文档要求设 `PYTHON`
- 陷阱 B：`root: "backend/"` 下执行 `git add {staged_files}` → **exit 128**（路径解析失败）。修法：改用 lefthook 内置 `stage_fixed: true`
