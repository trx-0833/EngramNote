## 清理方式

如需删除这些测试账号（连同数据），执行：

```bash
cd backend
python scripts/dev/e2e_cleanup.py   # 硬删除所有 e2e* 前缀测试账号及其全部数据
```

- 创建隔离账号 `e2eb<时间戳>@example.com`（密码同上）
- 测试结束自动清理笔记/项目/文件夹/目标（用户级数据可用 `e2e_cleanup.py` 硬清理）
