# ============================================================
# 音视频转写（可选，重量级）
# ============================================================
#
# 什么时候需要：上传 mp4 / mp3 / wav 等音视频，走 Qwen3-ASR 转写。
# 不需要它的场合：只处理 PDF / 图片 / Office / Markdown —— 那些功能完全不受影响。
#
# 用法：
#     pip install -r requirements.txt -r requirements-asr.txt
#     pip install torch --index-url https://download.pytorch.org/whl/cpu   # 按平台选轮子
#     python ../check_env.py --download-asr                                # 再下模型
#
# 为什么单独一份：torch 是 GB 级依赖，而它在 app/services/asr/asr_engine.py:11
# 是**模块顶层** import —— 放进主依赖会让每个不用 ASR 的用户都背上它。
#
# 依赖位置参考：
#   app/services/asr/asr_engine.py:11   → torch
#   app/services/asr/asr_engine.py:13   → qwen_asr
#   app/services/asr/audio_utils.py:11  → soundfile（已在主依赖里）
#
# 2026-09-24：下界由 `>=2.0.0` 对齐到实际在跑的 **2.14.0**（+cpu 轮子）。
# 原来的 2.0.0 等于形同虚设：它允许装到 2.0.x，而本项目从未在那个版本上跑过。
torch>=2.14.0
# 2026-10-21：**修掉一个装不上的 pin** —— 原写 `qwen-asr>=0.1.0`，
# 而 PyPI 上只有 0.0.1~0.0.6（`pip index versions qwen-asr` 报 LATEST: 0.0.6），
# 于是 `pip install -r requirements-asr.txt` 直接以
#   ERROR: No matching distribution found for qwen-asr>=0.1.0
# 失败 —— 即「文档里写的 ASR 安装路径根本走不通」。
# 对齐到实际在跑的版本，与上面 torch 的处理口径一致。
qwen-asr>=0.0.6
