# ============================================================
# MinerU 本地解析（可选，MinerU 4.x）
# ============================================================
#
# 什么时候需要：把 `MINERU_BACKEND` 设为 `pipeline`，用**本地模型**解析 PDF。
# 不需要它的场合：`MINERU_BACKEND=vlm-http-client`（默认）走 mineru.net 云端 API，
# 只需 `MINERU_API_TOKEN`，**不用装这份**。
#
# 用法：
#     pip install -r requirements.txt -r requirements-mineru.txt
#     mineru-kit models download --tier standard --small-backend onnx --vlm-engine llama-cpp --source modelscope
#     mineru-kit models verify   --tier standard --small-backend onnx --vlm-engine llama-cpp
#
# ## 2026-10-21：由 requirements-pdf-local.txt 重写而来（MinerU 3.x → 4.x）
#
# 三处实质变化：
#
# 1. **`mineru` 本体此前从未被任何清单声明过**。3.x 时代它靠"手动装"，
#    于是"照文档装完却跑不起来"是常态。这份清单把它显式登记。
# 2. **不再需要 `pyyaml` / `torchvision` / `ftfy` / `shapely` / `pyclipper`**。
#    4.x 的**基础包**已经把 `ftfy` / `shapely` / `pyclipper` / `PyYAML` 列为
#    核心依赖（实测干跑：装 `mineru>=4.0,<5` 会带进 ftfy-6.3.1 / shapely-2.1.2 /
#    pyclipper-1.4.0），而 `torchvision` 只属于 `mineru[torch]` extra。
# 3. **刻意不加任何 extra**。`mineru[torch]` 要求 `transformers<6,>=5.10.1`，
#    而本项目用 `sentence-transformers~=2.2.0`（transformers 4.x）——
#    装了会顶掉嵌入模型依赖链，bge-m3 直接失效。
#    基础包走 **ONNX CPU 小模型 + llama.cpp VLM**，不需要 torch/transformers，
#    正好适合无 CUDA 的机器。
#
# 取舍依据、实测耗时与内存数据见 docs/mineru-backend-decision.md。
#
# ⚠️ 升级到 4.x 会**移除** 3.x 的 `mineru.cli.common.do_parse` 等模块；
#    本项目的集成层已随之改为子进程调用 `mineru-kit parse`
#    （见 app/services/mineru/converter.py）。
#
# ## 2026-11-09：真机装完发现的两处必须补的约束
#
# 1. **`huggingface-hub<1.0`**（下面是显式约束）。
#    `mineru` 声明 `huggingface-hub[hf_xet]>=0.32.4`，pip 会挑最新的 1.33 ——
#    而 `transformers 4.57.6` 要求 `huggingface-hub<1.0,>=0.34.0`。
#    冲突方向很致命：**嵌入模型（bge-m3）走 transformers**，装完本地 MinerU
#    会让语义检索直接坏掉（`import transformers` 就报 version 检查失败）。
#    实测：`pip install "huggingface-hub>=0.34,<1.0"` 后两边都正常。
# 2. **`pypdfium2>=5.13,<6`** 已写进 `requirements.txt`（见那里 2026-11-09 的注释）：
#    `mineru` 与 `docvortex` 都要 `>=5.13.0`，原来的 `~=5.10.1` 会与之打架。
#
# 装完后的自检（本机实测通过，Windows / CPU / 无 CUDA）：
#     mineru-kit --version                     → MinerU 版本: 4.1.7
#     mineru-kit models verify --tier standard --small-backend onnx --vlm-engine llama-cpp
#                                              → MinerU-4_models_onnx: 正常
#                                                MinerU2.5-Pro-2605-1.2B-GGUF: 正常
#     python -c "from app.services.mineru.model_loader import *; print(local_backend_ready(load_config(None)))"
#                                              → (True, '')
mineru>=4.0,<5

# 见上面第 1 条：把 pip 的选择钉在 transformers 允许的区间里
huggingface-hub>=0.34,<1.0
